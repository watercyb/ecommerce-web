# E-Commerce Application

An e-commerce web application built with Vite and Node.js, featuring online shopping functionality, payment integration, and backend data management.

## Technologies

- JavaScript
- Vite
- Node.js
- Redis
- Stripe

## Key Features

- Product browsing
- Shopping cart management
- Payment processing with Stripe
- Backend API integration
- Redis integration

## Getting Started

1. Clone the repository.
2. Install dependencies for the frontend and backend.
3. Configure environment variables, including Stripe credentials.
4. Start the backend and frontend applications.
